# ADR-001 Better Auth 内部/供应商双实例

- 状态：已采纳
- 生效版本：MVP v1.0
- 关联需求：3.1、6.2、ADR-012

## 背景

平台同时服务内部采购人员与外部供应商，要求两套账号体系物理隔离：同一邮箱可以分别作为内部账号和供应商账号存在，会话不能互相冒用。

## 备选方案

1. 单实例 + `userType` 字段区分，鉴权时按角色拦截。
2. 两个 Better Auth 实例，分别挂载 `/api/auth/internal` 与 `/api/auth/supplier`。
3. 自研会话与密码体系。

## 决策

采用方案 2。两实例各自使用独立表（`internal_*` / `supplier_*`）与独立密钥（`INTERNAL_AUTH_SECRET` / `SUPPLIER_AUTH_SECRET`），守卫只接受对应实例的会话。

## 影响

- 正面：账号、会话、重置令牌完全隔离；越权风险低；同一邮箱可复用。
- 负面：账号创建、改密、重置逻辑需要按体系分别实现；迁移与运维需分别管理。
- 约束：新增认证能力（如 MFA）需两套同时评估。
