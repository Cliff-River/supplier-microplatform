# ADR-006 验收单为可选流程

- 状态：已采纳
- 生效版本：MVP v1.0
- 关联需求：4.3、12.4

## 背景

实际业务中并非所有订单都需要正式验收单。若强制上传才能完成订单，会阻塞小额或服务类订单。

## 备选方案

1. 验收单必填，未签署禁止完成订单。
2. 验收单可选，供应商上传后内部签署，不阻塞订单完成。

## 决策

采用方案 2：
- 供应商可在订单未完成时上传验收单（每单最多一条）。
- 内部可签署；签署前允许重传，签署后禁止替换。
- 订单完成后仍可签署已上传的验收单；未上传不影响完成订单。

## 影响

- 正面：流程灵活，满足留痕需要。
- 负面：内部需自行判断是否要求验收；报表统计需区分「无验收单」与「已验收」。
