# ADR-007 发票审核移出本期

- 状态：已采纳
- 生效版本：MVP v1.0
- 关联需求：1.6-B、4.4、12.5

## 背景

完整财务链路包括发票校验、对账与支付证明单（付款申请书）生成，涉及发票真伪查验、金额一致性、审批流与外部系统对接，复杂度高。

## 备选方案

1. 本期实现发票审核、校验与对账。
2. 本期仅保留发票/请款提交与内部查看记录，后续按「发票校验 → 对账 → 支付证明单」演进。

## 决策

采用方案 2。`invoice` 仅作为提交记录：记录发票号、金额、币种、备注与附件，可多次提交；不提供审核/驳回状态，不校验单张/累计金额上限与重复发票号。

## 影响

- 正面：控制 MVP 范围，先打通业务链路。
- 负面：财务核对仍在线下完成；后续演进需要新增状态机、校验规则与页面。
- 约束：平台不处理实际资金支付，不接入在线支付网关。
