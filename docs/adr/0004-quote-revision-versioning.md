# ADR-004 报价截止前可修改，版本递增

- 状态：已采纳
- 生效版本：MVP v1.0
- 关联需求：4.2、12.3

## 背景

供应商在询价截止前可能发现笔误或需要调整交期。若禁止修改，会产生大量线下沟通与重新发询价。

## 备选方案

1. 提交后不可修改。
2. 截止前可修改，每次覆盖并记录版本号。
3. 截止前可修改，每次新增一条报价记录。

## 决策

采用方案 2：同一 `(inquiryId, supplierId)` 只保留一条 `quote`，修改时 `version + 1` 并更新 `submittedAt`；每次提交都向内部联系人发送通知邮件。

## 影响

- 正面：降低笔误成本；内部始终看到最新报价并可感知版本变化。
- 负面：历史版本内容不保留，仅保留版本计数。
- 约束：截止后或询价非 `OPEN` 时服务端拒绝提交（`QUOTE_DEADLINE_PASSED` / `INVALID_STATE`）。
