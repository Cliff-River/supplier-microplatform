# ADR-010 关键操作写入 `audit_log`

- 状态：已采纳
- 生效版本：MVP v1.0
- 关联需求：5.4、9.3、12.7

## 背景

选标、合同回传、订单完成、账号停用等操作会影响供应商权益与业务结果，出现争议时需要可追溯的责任记录。

## 备选方案

1. 仅依赖应用日志文件。
2. 建立 `audit_log` 表，结构化记录关键操作，管理员可查询。

## 决策

采用方案 2。记录字段：操作者类型与 ID、操作名称、目标类型与 ID、摘要、变更前后数据、IP、User-Agent、时间。管理员通过 `/admin/audit-logs` 查询。

记录范围：

- 供应商、供应商账号的创建/编辑/停用/重置密码；
- 项目归档、询价发送/关闭/重开/作废/选标；
- 合同回传与签署完成、验收单签署；
- 订单完成/取消；
- 系统设置与邮件测试。

## 影响

- 正面：关键操作可追溯，满足审计要求。
- 负面：写操作需额外写日志；敏感字段需避免写入 `beforeData/afterData`（密码等不得记录）。
