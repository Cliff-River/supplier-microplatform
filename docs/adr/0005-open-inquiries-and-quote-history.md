# ADR-005 供应商开放列表 + 历史报价只读

- 状态：已采纳
- 生效版本：MVP v1.0
- 关联需求：1.5、8.2、12.1

## 背景

需求要求供应商只能查看被邀请且开放中的询价。但询价关闭后，供应商仍需要回看自己提交过的报价，以便内部复盘与后续合作。

## 备选方案

1. 关闭后询价对供应商完全不可见。
2. 开放列表只展示 `OPEN`，另设「我的报价历史」只读页。

## 决策

采用方案 2：
- `GET /api/supplier/inquiries` 仅返回被邀请且 `OPEN` 的询价。
- `GET /api/supplier/quote-history` 返回自己提交过的报价（含 `CLOSED` / `AWARDED`），只读。

## 影响

- 正面：既满足「开放中才可报价」的限制，又保留回看体验。
- 负面：供应商端需要多一个页面与接口；历史数据需按 `supplierId` 过滤避免越权。
