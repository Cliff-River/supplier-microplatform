# ADR-008 订单完成由项目创建者/管理员标记

- 状态：已采纳
- 生效版本：MVP v1.0
- 关联需求：4.3、12.4

## 背景

订单完成意味着内部确认履约结束，不应由供应商自行触发。需要明确责任人与权限边界，同时避免其他内部用户误操作。

## 备选方案

1. 任意内部用户可标记完成。
2. 仅订单所属项目的创建者或管理员可标记完成。
3. 由系统根据合同/验收/发票状态自动完成。

## 决策

采用方案 2。完成操作写入 `completedAt` 与审计日志；完成后服务端拒绝新的合同、验收单、发票提交，但已上传验收单仍可签署。

## 影响

- 正面：责任明确，减少误操作。
- 负面：创建者离职或长期不在时需要管理员兜底（管理员始终可操作）。
